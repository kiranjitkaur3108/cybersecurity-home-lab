#  Cybersecurity Home Lab

A hands-on cybersecurity portfolio documenting my journey toward an entry-level SOC Analyst / Cybersecurity Analyst role.

This repository contains practical labs covering networking, packet analysis, vulnerability assessment, SIEM, incident response, cloud security, and security automation.

##  Objective

Build practical cybersecurity skills through a multi-VM home lab and document each lab with commands, screenshots, findings, troubleshooting, and lessons learned.

##  Lab Environment

- Kali Linux — Security testing / analysis
- Ubuntu — Target / server / log source
- Windows — Target / log source
- VirtualBox — Virtualization
- Wireshark — Network traffic analysis
- Nmap — Network discovery and service detection
- Metasploit — Security testing
- Wazuh / Splunk — SIEM
- Python — Security automation
- PowerShell — Windows security automation
- Azure — Cloud security
